# M4c: `alder repl` and the M4 deferrals — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `alder repl` — a read-eval-print loop over a persistent scratch module (lets accumulate, expressions evaluate, `:type`/`:run`/`:run!`/`:html`/`:reload`/`:reset`), built on the scratch runner — plus the deferrals M4 folded in: the `alder run` child exits when its parent dies, `alder eval --run` gets a real session and the app's adapters, the experiment harness distinguishes its own failures from compiler bugs and seeds `--base` from a clean export, and scratch builds skip `go vet` where it buys nothing.

**Architecture:** Three tasks, bottom up. (1) Deferrals that touch neither eval nor the REPL: the generated server main exits on stdin EOF (so `alder run` holds a pipe and a SIGKILLed parent takes the child with it), and the Python harness gains `harness_error` and a `git archive` base. (2) The REPL's groundwork, made by refactoring `alder eval`: input items (`let` lines, expression) become a reusable parser; the generated mains (pure / Query / Task) move to one template with the session default and the adapters' capabilities; `scratch` gains a no-vet option. `alder eval --run` improves as a side effect and proves the groundwork. (3) `alder repl` itself and its chapters.

**Tech Stack:** Go stdlib (`bufio` line reader; no readline), `internal/scratch`, `rt.Show`, the existing `watch` poller of `alder run`; Python 3 stdlib for the harness.

**Spec:** `docs/superpowers/specs/2026-10-09-m4-test-repl-design.md` — "`alder repl`", "`alder eval`", "Deferrals folded in", "Error handling", "Testing", "Milestones (M4c)". Read it first.

```go
// TestRun_ChildExitsWhenParentDies: a dev server killed with SIGKILL (a harness timeout) takes
// the app with it: the child reads EOF on its stdin pipe and shuts down.
func TestRun_ChildExitsWhenParentDies(t *testing.T) {
	if testing.Short() {
		t.Skip("spawns processes")
	}
	// run `alder run` as a separate process (go run would add a layer: build the binary once in TestMain or use build/alder if present)
	bin := alderBinary(t) // the helper this file (or smoke_test.go) uses to build cmd/alder into a temp dir
	cmd := exec.Command(bin, "run", todosDir(t))
	cmd.Env = append(os.Environ(), "ALDER_ADDR=127.0.0.1:0")
	out, _ := cmd.StdoutPipe()
	if err := cmd.Start(); err != nil {
		t.Fatal(err)
	}
	// wait for the child to be up: alder run prints the proxy's address once the app is listening
	addr := waitForLine(t, out, "alder run: ", 60*time.Second)
	childPID := childOf(t, cmd.Process.Pid) // pgrep -P <pid> — the one app process
	_ = cmd.Process.Kill()                  // SIGKILL: no cleanup runs in the parent
	_, _ = cmd.Process.Wait()
	deadline := time.Now().Add(3 * time.Second)
	for time.Now().Before(deadline) {
		if !processAlive(childPID) {
			return
		}
		time.Sleep(50 * time.Millisecond)
	}
	t.Fatalf("the app (pid %d) is still running 3 s after its dev server was killed (addr %s)", childPID, addr)
}
```

Write `alderBinary`, `waitForLine`, `childOf` (`pgrep -P` or walking `ps -o pid,ppid`) and `processAlive` (`syscall.Kill(pid, 0)`) as small helpers if the file lacks them; Unix only (`//go:build unix` on this test file if needed).

**Files:**

**Interfaces:**
- Consumes: `parseItems`/`assemble`/`item`, `scratchMain`, `scratch.Check`, `scratch.CompileCheckedWith(…, Options{NoVet: true})`, `scratch.RunContext`, `evalDiags`/`evalMapDiag` (reuse for printing diagnostics with `input:L:C` → the REPL prints `line N` as the session line — see Design), `watch(dir, 300ms, stop, changed)` from `run.go`, `types.String`, `check.Result.Values`.
- Produces: `alder repl [dir] [--module Name]`; `runReplTo(args []string, stdin io.Reader, stdout, stderr io.Writer, interrupt <-chan struct{}) int` (the interrupt channel receives one value per Ctrl-C; `main.go` wires `signal.Notify`); exit 0 on `:quit`/EOF, 2 on usage or an app directory without `app/`.

**Design (binding):**
- **Session.** `lets []item` (each with the REPL line number it was entered at, `at int`) and the app dir. The session module source is `assemble(append(lets, exprItem))` with the expression `it = …` when evaluating, or `assemble(lets)` when checking a `let` alone. Every line is checked with `scratch.Check(dir, &scratch.Module{Name: modName, Source: src, Infer: true})` — milliseconds (M4a measured).
- **Reading.** `bufio.Scanner` with a 1 MB buffer; prompt `alder> ` (continuation `    …> `) written to stdout before each read; a line ending in `\` continues (the `\` removed, a newline kept); EOF → `:quit`. When stdin is not a terminal (tests, pipes) the prompts are still printed (simple; the transcripts in the book come from a terminal and look the same).
- **Line kinds.** `:cmd args` → a command; `let …` → a let item (parse via `parseItems(line + "\n0")`? No: `parseItems` of the let text alone returns one let item and `errNothing` for the missing expression — make `parseItems` return the items it found together with `errNothing`, and the REPL accepts that); anything else → an expression.
- **`let x = e`.** Check `assemble(lets ++ [new])`. Clean → keep it, print `x : T` (`types.String(U.Apply(Values["<mod>.x"]))`); diagnostics → print them and don't keep it. A later `let x` with the same name replaces the earlier one (the REPL removes the old item first; a notice `redefined x`).
- **An expression.** Check `assemble(lets ++ [it])`; diagnostics → print; a `Query` → `<Query> : Query T` (hint: `:run`); a `Task` → `<Task> : Task T` (hint: `:run!`); a `Select` → `<Select> : Select T` (hint as eval); else compile with `scratchMain(mainPure, false, it)` into `build/<app>/scratch/repl/` with `NoVet` and run it (`RunContext` with a context cancelled by the interrupt channel and `scratch.Timeout`); print `value : T`. A run failure → `alder repl: <msg>` (the stack-overflow rule as eval).
- **Commands.** `:type e` → check only, print `e : T` (the expression text echoed as typed); `:run e` → requires a Query: compile `scratchMain(mainQuery, hasAdapters, it)` and run with `ALDER_EVAL_DB=build/<app>/dev.db` (as eval `--run`); `:run! e` → requires a Task: `mainTask`, same DB, writes commit; a failure → `alder repl: the task failed: <msg>` (nothing committed: `eff.Run` rolls back); `:html e` → requires `Html a`: evaluate (pure main) and print the markup as returned (it is the rendered markup already); `:reload` → re-check the session against the app as it is now: lets re-checked one by one in order (each against the lets kept so far); a let that no longer checks is dropped with `dropped let x: <first diagnostic line>`; `:reset` → clears the lets; `:quit`/`:q` → exit 0; `:help`/`:h` → the command list; an unknown command → `unknown command :foo (try :help)`.
- **Auto-reload.** A goroutine runs `watch(dir, 300*time.Millisecond, stop, changed)` (from `run.go`; it watches `app/`, `adapters/`, `static/`); when a change arrives between two prompts the REPL does `:reload` before the next prompt and prints `app changed: session re-checked` (plus any drops). Implementation: the read loop selects on the scanner's lines (fed through a channel by a reader goroutine) and `changed`; a change during an evaluation is applied after it.
- **Interrupt.** `interrupt` (one value per Ctrl-C): during an evaluation → cancel its context, print `alder repl: interrupted`, keep the session; at the prompt → print `(use :quit or Ctrl-D to leave)` and re-prompt. `main.go`: `signal.Notify(ch, os.Interrupt)` with a buffered channel converted to `<-chan struct{}`.
- **Diagnostics.** Reuse `evalDiags` with a `mapLine` that maps a session-module line to `(item, line)`: print as `let x (line 3): …` for a let item (3 = the REPL line it was entered at) and `input:L:C` → `expr:L:C` for the current expression (L relative to the expression's own lines). Keep the caret/source line display evalDiags already does, over the right text.
