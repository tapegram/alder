# M3b Effects Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `load` and `update` run: effects lower to bind trees, a runtime interpreter executes them eagerly node by node against SQLite, and the to-do app's `load`/`update` are exercised end to end by a test — plus `alder dump` and the compiler fixes deferred from M3a.

**Architecture:** `Query`/`Task` values are data: `eff.Pure`, `eff.Bind` (continuation closures), `eff.Call` (an opaque effect step with a name, used for Db, Session, Log, Random, Time, Http and capabilities), `eff.Fail`, `eff.NotFound`. `eff.Run` walks the tree with an `Env` (store, session, clock, capability registry, log) — one transaction per `Task`, read-only for `Query`. `rt/db` holds table descriptors generated per `table`, a `Select` builder that is plain data, and the SQLite `Store`. `ir.Lower` stops skipping effectful values; `gen` emits the eff/db calls, table descriptors with `Encode`/`Decode`, and a Go interface per capability. No router, session cookie, or `main.go` yet (M3c).

**Tech Stack:** Go 1.27; `modernc.org/sqlite` (pure Go) is the only non-stdlib dependency, used by `rt/db` only; the compiler stays stdlib-only. `database/sql`.

**Spec:** `docs/superpowers/specs/2026-10-09-m3-codegen-runtime-design.md` (sections IR → effects, Emitter → Query/Task row, Runtime `rt/eff` and `rt/db`, Milestone M3b). Language reference: `book/07-effects.md`, `book/08-database.md`. Prior plan for conventions: `docs/superpowers/plans/2026-10-09-m3a-ir-emitter.md`.

## Global Constraints

- Go `1.27`, module `alder`; the compiler (`cmd/`, `internal/`) imports stdlib only; `rt/db` is the only package that imports `modernc.org/sqlite`; `go.sum` committed.
- `gofmt -l $(git ls-files '*.go')` empty; `go vet ./... && go test ./...` green before every commit; `python3 -m unittest` in `experiments/` green; `alder check examples/todos` clean; `alder build --emit examples/todos` exits 0; every `testdata/golden/gen_vet/*` program builds.
- Eager interpretation: `eff.Run` executes each `Call` when it is reached; no planning or batching.
- A `Task` runs in exactly one transaction: `Begin` before the first step, `Commit` after the result, `Rollback` on `ErrFail`, `ErrNotFound`, any store error, or a panic. A `Query` runs with no transaction and may only call read ops; a write op reached from a `Query` is an internal error (the checker forbids it).
- Storage mapping (book 08 gains this table): `Text`/brands of Text → `TEXT`; `Int` → `INTEGER`; `Float` → `REAL`; `Bool` → `INTEGER` 0/1; `Date` → `TEXT` `YYYY-MM-DD`; `Time` → `TEXT` RFC 3339 with nanoseconds in UTC; payload-less unions → `TEXT` constructor name; `Maybe T` → nullable column of T's type; ids are 20-char URL-safe random strings generated by the store.
- Generated file names are `<Module with '.'→'__'>_alder.go` (Go treats the part after the last `_` as a possible GOOS/GOARCH/test suffix, so `_alder` neutralizes it; a `.alder.go` suffix would NOT work because Go truncates at the first `.`).
- Diagnostic codes stay stable; new parse messages keep E0001. Commit messages end with the two attribution lines given in the conversation.

## Review Focus

1. A `Task` that fails after an insert — the insert must not persist (Task 3 `TestRun_RollbackOnFail`, Task 4 `TestStore_RollbackLeavesNoRow`).
2. `Db.update` whose function changes the `@id` field — the book says the function may not; the runtime must refuse (Task 4 `TestStore_UpdateRejectsIdChange`).
3. Two inserts violating `@unique` in one task — the second fails the task and the first is rolled back (Task 4 `TestStore_UniqueViolationFailsTask`).
4. A `Time` stored and read back in a different local zone — equal instants (Task 4 `TestStore_TimeRoundTripUTC`).
5. `Query.all []` / `Task.all []` — succeeds with an empty list, no store calls (Task 3 `TestRun_AllEmpty`).

**Interfaces:**
- Produces (exact; Tasks 5–6 emit against these names):
  ```go
  package eff

  // Query and Task are the same tree; Kind records which the checker proved.
  type Kind int
  const ( KQuery Kind = iota; KTask )

  // A step is one node. Generated code only sees the constructors below.
  type Step[T any] interface{ step() }     // sealed

  type Query[T any] struct{ node node }    // node is the untyped tree (pure/bind/call/fail/notFound)
  type Task[T any]  struct{ node node }

  func Pure[T any](v T) Task[T]                                   // also usable where a Query is expected via Q()
  func Q[T any](t Task[T]) Query[T]                               // reinterpret a tree as a Query (generated code uses it for Query positions)
  func Bind[A, B any](e Task[A], f func(A) Task[B]) Task[B]
  func Map[A, B any](f func(A) B, e Task[A]) Task[B]
  func All[A any](es []Task[A]) Task[[]A]                         // in order; stops at the first failure
  func Fail[T any](msg string) Task[T]
  func NotFound[T any]() Task[T]
  // Call is one effect step. name is for the log ("Db.get Todo", "Password.verify"); write says
  // whether it needs a transaction; fn runs with the Env and returns the value or an error.
  func Call[T any](name string, write bool, fn func(*Env) (T, error)) Task[T]

  type Env struct {
      Ctx     context.Context
      Store   Store            // rt/db-independent: the interface below
      Tx      Tx               // non-nil while a Task runs
      Session any              // the app's session value; SessionPut replaces it
      Caps    map[string]any   // "Auth.Login.Password" → implementation
      Now     func() time.Time
      Log     func(level, msg string)
      Trace   []string         // every Call name in order (dev log / tests)
  }
  type Store interface {
      Begin(ctx context.Context) (Tx, error)
  }
  type Tx interface {
      Commit() error
      Rollback() error
  }
  type ErrFail struct{ Msg string }      // Task.fail / @unique / capability failure
  var ErrNotFound = errors.New("not found")
  func (e *ErrFail) Error() string

  // Run interprets eagerly, node by node. kind KTask: Begin, run, Commit (or Rollback on any error
  // or panic, re-panicking after rollback). kind KQuery: no transaction; a Call with write=true
  // returns an internal error. The result is (value, nil) | (zero, *ErrFail) | (zero, ErrNotFound) |
  // (zero, other error from the store or a capability).
  func Run[T any](env *Env, kind Kind, t Task[T]) (T, error)
  func RunQuery[T any](env *Env, q Query[T]) (T, error)       // = Run(env, KQuery, Task[T]{q.node})
  ```
  `node` is an unexported sum: `pure{v any}`, `bind{e node; f func(any) node}`, `call{name string; write bool; fn func(*Env) (any, error)}`, `fail{msg}`, `notFound{}`. The generic constructors wrap/unwrap `any` at the boundary; `Bind`'s `f` is adapted to `func(any) node`.

**Interfaces:**
- Produces (exact):
  ```go
  package db

  type ColType int
  const ( CText ColType = iota; CInt; CFloat; CBool; CDate; CTime; CEnum )
  type Column struct {
      Name     string
      Type     ColType
      Nullable bool          // Maybe T
      Enum     []string      // CEnum: constructor names in declaration order
      Unique   bool
      Ref      string        // table name for @ref, "" otherwise
  }
  // Table describes one `table`. Generated code builds one per table as a package var.
  type Table[T any] struct {
      Name       string           // "Todo" (module-qualified: "Todo.Todo" → SQL table "Todo__Todo")
      Columns    []Column         // in declaration order, including the id column
      ID         string           // the @id column
      Created    string           // @created column or ""
      Updated    string           // @updated column or ""
      Encode     func(T) []any    // column values in Columns order (id included), using Encode* helpers
      Decode     func([]any) (T, error)
      ReadID     func(T) string
      SetID      func(T, string) T
  }
  // Insert values: the record without id/created/updated; generated code passes a func that
  // yields the column values in Columns order with nil at those three positions.

  // Select is data; the store turns it into SQL.
  type Select[T any] struct {
      Table  *Table[T]
      Where  []Cond
      Order  []Order
      Limit  *int64
      Offset *int64
  }
  type CondKind int
  const ( Eq CondKind = iota; Ne; Lt; Le; Gt; Ge; Contains; In; IsNull; IsNotNull; And; Or; Not )
  type Cond struct {
      Kind  CondKind
      Col   string
      Val   any        // encoded scalar, or []any for In
      Subs  []Cond     // And/Or/Not
  }
  type Order struct{ Col string; Desc bool }
  func From[T any](t *Table[T]) Select[T]
  func Where[T any](c Cond, s Select[T]) Select[T]
  func OrderBy[T any](o Order, s Select[T]) Select[T]
  func Limit[T any](n int64, s Select[T]) Select[T]
  func Offset[T any](n int64, s Select[T]) Select[T]
  func CEq(col string, v any) Cond  // … CNe, CLt, CLe, CGt, CGe, CContains, CIn(col, []any), CIsNull, CIsNotNull, CAnd(cs), COr(cs), CNot(c)
  func Asc(col string) Order; func Desc(col string) Order

  // Store: what eff ops call. Tx embeds eff.Tx.
  type Store interface {
      eff.Store
      Get(ctx context.Context, tx Tx, table string, id string) (row []any, found bool, err error)   // tx may be nil (Query)
      Query(ctx context.Context, tx Tx, table string, cols []Column, sel SQL) (rows [][]any, err error)
      Count(ctx context.Context, tx Tx, table string, sel SQL) (int64, error)
      Insert(ctx context.Context, tx Tx, table string, cols []Column, idCol, createdCol, updatedCol string, vals []any) (id string, err error)
      Update(ctx context.Context, tx Tx, table string, cols []Column, idCol, updatedCol, id string, vals []any) error
      Delete(ctx context.Context, tx Tx, table string, idCol, id string) error
  }
  ```
