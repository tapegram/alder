# App Gaps Implementation Plan (#308 → #310 → #309 → #311)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A write route's handler is named after its method (`Add.post`), any module may hold a
query that needs a session key and says so with `requires`, a handler can answer with views it
built (`Response.replace`) and remove elements, and `Text.Email` is lower-case by construction.

**Architecture:** All four are checker-and-runtime changes over existing machinery. #308 swaps the
literal `"update"` for `handlerName(method)` and adds a per-site migration warning that
`alder fmt` applies. #310 moves the last case of `narrowed` from "module declares a route" to "the
value's signature states the key", with a `requires` clause on `ValueDecl`. #309 adds a response
kind, two Datastar event shapes and a test-browser answer. #311 folds at every construction site
and adds one migration step kind whose mark enters the schema hash.

**Tech Stack:** Go (compiler, runtime, CLI), Alder (`stdlib/`, `testdata/corpus`, `examples/`),
SQLite/Turso, Datastar v1.0.0 (vendored), tree-sitter (`tree-sitter-alder/`, CLI 0.27.1 via
`scripts/ts.sh`), Playwright browser tests (`-tags browser`), markdown (`book/`).

**Spec:** `docs/superpowers/specs/2026-11-24-app-gaps-design.md`. Read it first, **including the
rulings R1–R16 at its end, which override the sections above them**. In particular R9 renames
`Response.patch` to **`Response.replace`** everywhere (the `Answer` constructor is **`Replaced`**),
and R10 **deprecates `render r`** with a warning for one release. Each task names the spec
sections it implements; they are part of its requirements.

## Review Focus

1. **A route-module helper still under W0014 (no clause) used from another module.** Callers see
   *S*; if *S* were empty the caller would escape the check. During the W0014 release a
   route-module helper's effective *S* is *S* ∪ *I*. Test in Task 8.
2. **Mutually recursive helpers with needs, across two modules.** Inference must terminate and
   both must be told to state the key. Test in Task 6.
3. **`Text.Email "Ada@X.com" == ` a decoded form value `ada@x.com`.** A literal in a test and a
   decoded value must compare equal, and a non-ASCII capital (`É@x.com`) folds in Alder. Test in
   Task 17.
4. **A removal id that is not a plain CSS identifier** (`3`, `member-3.a`). `IDSelector` must
   escape it and the test browser must still find the element. Tests in Tasks 12 and 15.
5. **`alder fmt` on a project where a handler is referenced from a test in another module.** All
   files must be rewritten in one run and the run must be idempotent. Test in Task 2.
