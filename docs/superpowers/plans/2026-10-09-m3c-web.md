# M3c Web Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `alder build examples/todos` produces a binary that serves the to-do app in a browser: pages, messages, forms with errors, a signed-cookie session, Datastar in-place patching with a no-JS fallback — exercised end to end by an `httptest` test and a binary smoke test.

**Architecture:** `rt/web` owns the request plumbing: a path router, the signed cookie session, field decoding with refinements, request-scoped form state, responses (page / 303 / 404 / 500 / SSE patch), panic recovery, static files. `rt/datastar` serves the vendored script and writes SSE `datastar-patch-elements` events. `rt/html` controls become *deferred* nodes filled at render time from the form state. The generated package `app` gains a `routes__alder.go` with one typed handler per page and message (the chapter-6 lifecycle, generated — the rules live in `web` helpers), per-page `Params` and per-form decoders, brand `where` predicates, exported capability interfaces (`Cap__…`), an `app.Caps` struct and `app.Serve`. Hand-written capability adapters live in the app directory as a Go package (`<app>/adapters`, `package adapters`, importing `app`), copied into `build/<app>/adapters/`; a generated `build/<app>/cmd/main.go` wires `adapters.Caps()` and serves (option B).

**Tech Stack:** Go 1.27 stdlib (`net/http`, `crypto/hmac`, `encoding/json`); `modernc.org/sqlite` (already); Datastar v1 script vendored into `rt/datastar/datastar.js` (pinned; the version recorded in `rt/datastar/VERSION`).

**Spec:** `docs/superpowers/specs/2026-10-09-m3-codegen-runtime-design.md` (Runtime `rt/web`/`rt/datastar`, "Datastar patching", "Data flow", Milestone M3c). Book: `book/06-pages.md` ("The request lifecycle", `form`, `Nav`, `App`), `book/05-html.md` (forms), `book/04-types.md` (refinements), `book/07-effects.md` (capabilities).

## Global Constraints

- Go `1.27`, module `alder`; `cmd/` and `internal/` import stdlib only; `rt/web` and `rt/datastar` import stdlib only; `go.sum` committed.
- `gofmt -l $(git ls-files '*.go')` empty; `go vet ./... && go test ./...` green before every commit; `python3 -m unittest` in `experiments/` green; `alder check examples/todos` clean; `alder build examples/todos` exits 0 and writes `build/todos/todos` (the binary); every `gen_vet` program builds.
- The request lifecycle is exactly `book/06-pages.md` "The request lifecycle": GET → decode params (404) → `requires` (303 to `App.login`) → `load` → `view`; POST → decode message params + form (404 / re-render with errors, `update` not called) → `requires` → `load` → `update` → `Rerender` (load → view → full page, or SSE body patch when the request carries `Datastar-Request: true`) | `Redirect` (303) | `Reject text` (re-render with the form-level error); Task failure → `App.error`, 500; `Query.notFound` → `App.notFound`, 404.
- One `eff.Env` per request (`Run` mutates it); `Env.Session` holds the App session value; a `Task` that fails leaves the cookie unchanged.
- Session cookie: name `alder_session`, value = base64url(JSON) + "." + base64url(HMAC-SHA256), key from `ALDER_SECRET` (any length ≥ 16 bytes) else a fixed dev key with a startup warning on stderr; `HttpOnly`, `SameSite=Lax`, `Path=/`, `Max-Age` 30 days; an invalid or missing cookie is the default session (field defaults; `Maybe` → Nothing).
- Form/param field types are those `book/06` allows: `Text`, `Int`, `Float`, `Bool`, `Date`, brands of those (refinements checked), payload-less unions, `Maybe` of those; defaults make a field optional; `Bool` is a checkbox, `False` when absent; `Text.Secret` renders `type="password"`, is never echoed back on re-render, never logged.
- Generated-only names keep the `__` marker scheme; new exported markers `Cap__`, `Args__`, `Route__` (see Task 4) — `names.go` documents them and `TestGoNameInjective` covers them.
- Port from `ALDER_PORT` (default `8080`); `ALDER_DB` path (default `<app>.db` next to the binary; `:memory:` allowed); `ALDER_DEV=1` enables dev mode (schema recreate, error text in 500 pages); static files from `<app>/static/` served at `/static/`.

## Review Focus

1. A POST with a stale or tampered session cookie — must be treated as the default session (then `requires` redirects), never a 500 (Task 2 `TestSession_TamperedCookieIsDefault`).
2. A form field named like a message param (`id` in both the URL query and the form body) — the message param comes from the query, the form field from the body, no cross-talk (Task 4 `TestDecode_ParamsAndFormDontMix`).
3. `Reject` after writes — the writes and session commit (book 06), the page re-renders with the error and the submitted values, status 200, and under Datastar a body patch (Task 5 `TestE2E_RejectKeepsWrites`).
4. A `requires` page hit with Datastar headers while logged out — must answer the 303 the browser can follow, not an SSE patch of the login page (Task 5 `TestE2E_RequiresUnderDatastar`).
5. A 500 from a capability error must not leak the error text outside dev mode (Task 2 `TestResponse_ErrorHidesTextInProd`).

  // form's name ("NewTodo"); Values are the submitted raw strings by field; Errors by field;
  // FormError is the form-level message (Reject text or "" ). Secret fields are never in Values.

  // `selector body`, `mode outer`, and `elements <html of the new body>` (one `elements` line per
  // line of HTML), then flushes. Content-Type text/event-stream.

**Interfaces:**
- Produces:
  ```go
  package web

  // Route is one page (GET) or message (POST) endpoint. Pattern: "/", "/todos/{id}"; messages use
  // "/_m/<Module>/<Msg>". Handle gets the matched path params; it returns a Response.
  type Route struct {
      Method  string            // "GET" | "POST"
      Pattern string
      Handle  func(rq *Request) Response
  }
  type Request struct {
      Ctx     context.Context
      HTTP    *http.Request
      Params  map[string]string   // path params
      Query   url.Values
      Form    url.Values          // POST body (parsed); nil for GET
      Session any                 // decoded by the Router from the cookie via Options.Session
      Env     *eff.Env            // fresh per request: Store, Caps, Now, Log, Session set; Ctx = r.Context()
      Datastar bool
      Dev     bool
  }
  // Responses. Page renders a full document (200) or, when rq.Datastar and the response says so,
  // an SSE body patch. Redirect is 303. NotFound renders App.notFound (404). Error renders App.error
  // (500; in dev the message is appended as a comment). Each carries the session to store.
  type Response struct {
      Status   int
      Node     html.Node         // the document for Page/NotFound/Error
      State    *html.FormState   // nil or the form state to render with
      Location string            // Redirect
      Patch    bool              // Page: answer a Datastar request with a body patch
      Session  any               // to store in the cookie (nil = unchanged)
      Err      error             // Error
  }
  func PageResponse(doc html.Node, st *html.FormState, session any, patch bool) Response
  func RedirectResponse(location string, session any) Response
  func NotFoundResponse(doc html.Node) Response
  func ErrorResponse(doc html.Node, err error) Response

  type Options struct {
      Store     eff.Store                 // db store (db.Store); nil only for apps without tables
      Caps      map[string]any
      Now       func() time.Time
      Log       func(level, msg string)
      Dev       bool
      Secret    []byte                    // cookie key; nil → dev key + warning
      Session   SessionCodec              // generated: zero value, JSON encode/decode of the App session type
      StaticDir string                    // "" → none
      ErrorDoc  func(err error) html.Node // App.error
      NotFoundDoc func() html.Node        // App.notFound
      Login     string                    // App.login page path (for `requires`)
  }
  type SessionCodec interface {
      Default() any
      Encode(any) ([]byte, error)
      Decode([]byte) (any, error)
  }
  func NewRouter(routes []Route, opts Options) http.Handler
  // The handler: recover panics → 500 via ErrorDoc; serve /_alder/datastar.js and /static/*;
  // match method+pattern (trailing slash tolerant; a GET to an unknown path → NotFoundDoc 404;
  // a POST to an unknown message → 404); parse the form for POST (max 1 MiB); decode the session;
  // build Env; call Handle; write the Response: Page → full HTML (or SSE patch of <body> when
  // rq.Datastar && Patch) with Content-Type text/html; Redirect → 303 Location; set the cookie
  // when Session != nil (and clear it when the session equals Default? no: always store).

  // session.go
  func Sign(key, payload []byte) string             // base64url(payload) + "." + base64url(hmac)
  func Verify(key []byte, cookie string) ([]byte, bool)
  const CookieName = "alder_session"
  func DevKey() []byte                               // fixed; NewRouter logs "warning: ALDER_SECRET not set …" once
  ```
  `requires` is not a router concern: the generated handler checks it and returns `RedirectResponse(opts.Login, nil)`; the router exposes `rq.Login` (copied from Options) for that.

### Task 3: Field decoding with refinements

**Files:**
- Create: `rt/web/decode.go`, `rt/web/decode_test.go`

**Interfaces:**
- Produces:
  ```go
  package web
  type FieldError struct{ Field, Message string }
  // Decoder helpers the generated decoders call. Each takes the raw values, the field name and
  // returns the value plus an error message ("" when ok). Missing = the key is absent.
  func Text(v url.Values, name string, required bool) (string, bool /*present*/)
  func Int(v url.Values, name string) (int64, string)        // "" ok; "must be a whole number"
  func Float(v url.Values, name string) (float64, string)
  func Bool(v url.Values, name string) bool                   // checkbox: present and != "" && != "false"
  func Date(v url.Values, name string) (rt.Date, string)      // YYYY-MM-DD; "must be a date (YYYY-MM-DD)"
  func Enum(v url.Values, name string, names []string) (int, string) // index into constructor names; "must be one of a, b, c"
  // Refinements: generated code calls Check(ok, name, msg) → FieldError when !ok.
  func Missing(name string) FieldError                         // "is required"
  // Messages for the stdlib brands (rt/web owns them so the book can quote them):
  func NonEmpty(s string) bool   // strings.TrimSpace(s) != ""      msg "must not be empty"
  func Email(s string) bool      // has "@" with text both sides       msg "must be an email address"
  func URL(s string) bool        // parses with a scheme and host      msg "must be a URL"
  func Secret(s string) bool     // s != ""                             msg "must not be empty"
  ```
  Decoding a field of type `Maybe T`: absent or "" → Nothing; else decode T. A field with a default: absent → the default (generated). Errors accumulate; the generated decoder returns `(value, []FieldError)` and the handler re-renders when `len(errs) > 0`.
