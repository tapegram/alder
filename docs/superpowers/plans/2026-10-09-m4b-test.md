# M4b: `alder test` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `alder test` runs every `test` declaration of an app — pure `Bool` tests and effect tests (`Task Bool`) against a fresh in-memory database — and reports each failure with both sides of its `==` and the effect trace; `Test.run` lets a test observe a task's failure and its trace under a savepoint.

**Architecture:** Three layers, bottom up. (1) The runtime gains savepoints (`rt/db`), a reentrant inner run (`rt/eff.RunInner`) and a test runner package (`rt/testing`, imported as `rtesting`) that owns the per-test environment and the report. (2) The compiler gains the `Test` stdlib module, two checker rules, IR nodes for tests and `Test.run`/`Test.trace`, and emission of a `Tests` table into `app__alder.go`. (3) `cmd/alder test` compiles the app through `internal/scratch` with a ten-line generated main and runs the binary; the example app gets tests; chapter 10 is rewritten and verified by `go test ./book`.

**Tech Stack:** Go (stdlib + `modernc.org/sqlite` already vendored), the existing `internal/scratch` runner, `rt.Show`, the book verifier.

**Spec:** `docs/superpowers/specs/2026-10-09-m4-test-repl-design.md` — sections "The `Test` stdlib module", "`alder test`", "Error handling", "Testing", "Milestones (M4b)". Read it first; the plan argues from it.

## Review Focus

1. **A test that panics** (a `/ 0` inside a pure test, or an unwired capability called from a task test): expected — that test fails with the panic's message (`capability X is not wired in tests` for the capability), the runner continues with the next test, the summary counts it. Test in Task 1 (`TestRun_PanicIsFailure`, `TestRun_UnwiredCapability`).
2. **`Test.run` of a task that fails after writing**: expected — the write is undone (a `Db.count` after it sees the earlier state), the enclosing test's own earlier writes survive, and the result is `Err "…"` with the inner trace. Test in Task 1 (`TestInner_RollbackToSavepoint`) and end to end in Task 3 (the example's "Toggle by another user is not found" test).
3. **Two `Test.run`s in one test, nested or in sequence**: expected — distinct savepoint names, each window holds only its own steps, the outer trace holds everything including the `Test.run` entries. Test in Task 1 (`TestInner_NestedAndSequential`).
4. **A test body that is neither `Bool` nor `Task Bool`** (`test "x" = 1`, `test "y" = Query.succeed True`): expected — one E0003 naming the test and the type found, no cascade, no lowering. Test in Task 2 (corpus `E0003-test-not-bool`, `E0003-test-query`).
5. **`-run` matching nothing / an app with no tests**: expected — `0 passed, 0 failed`, exit 0, and under `--json` an empty stream (no object), not a crash. Test in Task 3 (`TestTest_NoMatch`).

**Design (binding):**
- Savepoints in SQLite: `SAVEPOINT <name>`, `RELEASE <name>`, `ROLLBACK TO <name>` executed on the transaction's querier (`s.on(tx)`); `name` is `alder_t<n>` with `n` a per-process counter in `rtesting` (`atomic.Int64`), so nested and sequential savepoints never share a name. A savepoint outside a transaction is an error (`db: savepoint outside a transaction`).
- `RunInner` is `interpret(env, env.Kind, t.node)` with a guard: when `env.Kind` is not `KTask` it returns an `ErrInternal` error ("RunInner outside a running Task"). It does not touch `env.Tx`, `env.Session` or `env.Trace` beyond what interpret does.
- `Inner`: `session := env.Session`; `start := len(env.Trace)`; `tx, err := env.Transaction()` (begins the test's transaction on first use); if `env.Store` implements `db.Savepointer` and `tx != nil`, `Savepoint`; run; on success `Release` and return `ok=true`; on `*eff.ErrFail` or `eff.ErrNotFound`: `RollbackTo`, `env.Session = session`, return `ok=false, msg`; on any other error return it (after `RollbackTo`, so the store is consistent). `trace` is a copy of `env.Trace[start:]`. The `Test.run` Call's own name is appended by `interpret` before `Inner` runs, so `start` already excludes it.
- `Trace`: a copy of `env.Trace[:len-1]` (the last entry is the `Test.trace` step itself; when the trace is empty, empty).
- `Eq`: `rt.Eq(l, r)` plus `lastSides = [2]string{rt.Show(l), rt.Show(r)}; hasSides = true` in package variables; `Run` clears them before each case and reads them after (tests run sequentially in one goroutine; document this).
- `Run`, per case: `store, _ := db.OpenSQLite(":memory:")`, `store.Ensure(ctx, o.Tables, true)`, `env := &eff.Env{Ctx: ctx, Store: store, Caps: o.Caps (an empty map when nil), Session: o.Session, Now: func() time.Time { return o.Now }}`; a pure case is called inside a recover; a task case is `eff.Run(env, eff.KTask, c.Task())` inside a recover; `OK = value && err == nil`; `Error` is the error text or the recovered panic's text with `alder: capability "X" is not wired` rewritten to `capability X is not wired in tests` (the regexp `cmd/alder/eval.go` uses); `Trace = env.Trace`; `Left/Right` from `Eq`'s record when set; `Ms` wall time; `store.Close()`. `o.Run` filters on `Module + " \"" + Name + "\""`. A nil `Now` means `2026-01-01T00:00:00Z` (`Main` always passes it).
- `Main` output (text): per case `ok   Todo "countOpen ignores done todos"` or `FAIL Todos.Index "Toggle flips done"` followed by indented lines `left:  <Show>`, `right: <Show>` (when sides were recorded), `error: <text>` (when set), `trace: [Db.get Todo, Db.update Todo]` (for a task test that failed; the list printed as `rt.Show` of a `[]string`); then `N passed, M failed`. `--json`: one JSON object per line `{"module":…,"name":…,"ok":…,"left":…,"right":…,"error":…,"trace":[…],"ms":…}` (omit empty strings; `trace` always present, `[]` when empty) and nothing else on stdout; the summary goes to stderr in JSON mode. Exit 1 when any failed, 0 otherwise, 2 for a bad `-run` regexp.

```go
// Savepoint opens savepoint name inside tx (Savepointer). name must be an identifier the
// caller controls (rtesting uses alder_t<n>); it is not quoted.
func (s *SQLite) Savepoint(ctx context.Context, tx Tx, name string) error {
	return s.savepointStmt(ctx, tx, "SAVEPOINT "+name)
}

// Release commits savepoint name into its transaction (Savepointer).
func (s *SQLite) Release(ctx context.Context, tx Tx, name string) error {
	return s.savepointStmt(ctx, tx, "RELEASE "+name)
}

// RollbackTo undoes everything since savepoint name was opened and keeps the savepoint
// (Savepointer); the transaction's earlier writes stay.
func (s *SQLite) RollbackTo(ctx context.Context, tx Tx, name string) error {
	return s.savepointStmt(ctx, tx, "ROLLBACK TO "+name)
}

func (s *SQLite) savepointStmt(ctx context.Context, tx Tx, stmt string) error {
	if tx == nil {
		return errors.New("db: savepoint outside a transaction")
	}
	q, err := s.on(tx)
	if err != nil {
		return err
	}
	_, err = q.ExecContext(ctx, stmt)
	return err
}
```

In `rt/eff/run.go`:

```go
// RunInner interprets t inside the Run that is running env — the same transaction, the same
// Trace, the same Session — and returns its result or error without committing, rolling back
// or restoring anything: the enclosing Run decides. A Call's function uses it to run a Task it
// was given (Test.run). Outside a running Task it is an internal error.
func RunInner[T any](env *Env, t Task[T]) (T, error) {
	var zero T
	if env.Kind != KTask || env.beginTx == nil && env.Tx == nil && env.Store != nil {
		return zero, fmt.Errorf("eff: %w: RunInner outside a running Task", ErrInternal)
	}
	v, err := interpret(env, KTask, t.node)
	if err != nil {
		return zero, err
	}
	return as[T](v), nil
}
```

Note the guard: `env.Kind` is `KTask` only while `Run` runs a Task (`Run` sets and restores it). `env(s)` in the tests has `Kind` zero (`KQuery`), so the third test passes; simplify the condition to `env.Kind != KTask` if the `beginTx` clause reads as noise — it is `Kind` that carries the information.

```go
// Package rtesting runs an app's `test` declarations: alder test's generated main calls Main
// with the Tests table app__alder.go emits. Each case runs against a fresh in-memory SQLite
// database with the app's tables, a fixed clock and the capabilities it was given; Inner is
// what the generated code of Test.run calls.
package rtesting

var savepoints atomic.Int64

func Inner[T any](env *eff.Env, t eff.Task[T]) (v T, msg string, ok bool, trace []string, err error) {
	session := env.Session
	start := len(env.Trace)
	tx, err := env.Transaction()
	if err != nil {
		return v, "", false, nil, err
	}
	sp, _ := env.Store.(db.Savepointer)
	name := "alder_t" + strconv.FormatInt(savepoints.Add(1), 10)
	if sp != nil && tx != nil {
		if err := sp.Savepoint(env.Ctx, tx, name); err != nil {
			return v, "", false, nil, err
		}
	}
	v, rerr := eff.RunInner(env, t)
	trace = append([]string(nil), env.Trace[start:]...)
	if rerr == nil {
		if sp != nil && tx != nil {
			if err := sp.Release(env.Ctx, tx, name); err != nil {
				return v, "", false, trace, err
			}
		}
		return v, "", true, trace, nil
	}
	if sp != nil && tx != nil {
		if err := sp.RollbackTo(env.Ctx, tx, name); err != nil {
			return v, "", false, trace, err
		}
	}
	env.Session = session
	var f *eff.ErrFail
	switch {
	case errors.As(rerr, &f):
		return v, f.Msg, false, trace, nil
	case errors.Is(rerr, eff.ErrNotFound):
		return v, "not found", false, trace, nil
	}
	return v, "", false, trace, rerr
}
```
