# Plan: metrics endpoint, slow-request warnings, `alder logs --since` (#92)

Spec: `docs/superpowers/specs/2026-10-30-metrics-design.md` (binding). Stacked on #93
(`issue-56-observability`). Test-first, one commit per task.

Baseline before any change: `rt/web`'s FilteredNoCost request (`/p?key=s3cret&seed=7&next=…`,
no hook) allocates 51 per request on #93 (go1.27.2). Task 6 pins it.

## 1. `rt/eff`: `Stats`

- `rt/eff/eff.go`: `type Stats struct{ Exec, Query int; ExecDur, QueryDur time.Duration }`,
  `(*Stats).Add(query bool, d)`, `Env.Stats *Stats`.
- Test `rt/eff/stats_test.go`: `TestStats_Add`.

## 2. `rt/db`: statements counted

- `rt/db/sqlite.go` `recQ`: time a statement when the Env has `Rec` or `Stats`; add to each
  set. Exec → exec; Query and QueryRow → query. The `Rec == nil && Stats == nil` path unchanged.
- Test `rt/db/stats_test.go`: `TestStats_Counted` (exec + query: 1/1, durations > 0; neither
  set: Stats untouched, nothing recorded).

## 3. `rt/metrics` (new, stdlib only)

- `metrics.go`: `Collector` (one mutex; `reqKey{route, method string; class uint8}` struct map
  key; histogram per `{route, method}`; step and statement counters; start time), `New`,
  `InFlight`, `Request`, `Steps`, `Statements`, `Write` (HELP/TYPE, the spec's order, series
  sorted, label escaping, runtime/metrics at scrape).
- `env.go`: `FromEnv` (getenv seam), `Authorized` (Bearer, `subtle.ConstantTimeCompare` on
  SHA-256 digests so the length is not leaked either).
- `metrics_test.go`: `TestFromEnv`, `TestAuthorized`, `TestCollector_Exposition`,
  `TestCollector_StatusClass`, `TestCollector_MethodOther`, `TestCollector_HistogramBuckets`,
  `TestCollector_LabelEscape`, `TestCollector_Steps`, `TestCollector_Statements`,
  `TestCollector_Runtime`, `TestToken_NeverShown` (the token is in no error, no exposition,
  no `%v`/`%+v`/JSON of the Collector), `BenchmarkRequest` + `TestRequest_NoAlloc`.

## 4. `rt/applog`: the slow line

- `Access` gains `Route`, `Stmts`, `DBDur`, `Slow`. A Slow record is written at Warn (Quiet or
  not) with ` slow route=… steps=N db=S/ms` (text) or `slow, route, steps, db_stmts, db_ms`
  (JSON); a non-slow record is unchanged. `SlowFromEnv` (getenv seam).
- Tests in `rt/applog/slow_test.go`: `TestText_AccessSlow`, `TestJSON_AccessSlow`,
  `TestAccess_SlowAtWarn`, `TestSlowFromEnv`.

## 5. `rt/web`: endpoint, route label, stats, in-flight, slow

- `Options.Metrics`, `Options.SlowAfter`; `route.pattern`; `tracker.route`, `tracker.stats`;
  `MetricsPath`; `rt.metrics` (200 / 401); in-flight around routing; `Env.Stats` set only when
  metrics or slow is on; deferred block fills Route/Stmts/DBDur/Slow, then Access, then
  `Request` + `Statements`; `Steps` beside `tw.steps`. Route labels for files: `/static/`,
  `/_alder/`, `/_dev`, `(none)`.
- Tests `rt/web/metrics_test.go`: `TestMetrics_Off`, `TestMetrics_Scrape`, `TestMetrics_Token`,
  `TestMetrics_Route404`, `TestMetrics_FileRoutes`, `TestMetrics_InFlight`,
  `TestMetrics_Effects`, `TestMetrics_Statements`, `TestMetrics_NoSessionNoPanel`,
  `TestMetrics_HostileLabels` (hostile paths, queries and methods make no new series),
  `TestMetrics_TokenNotLogged`, `TestSlow_Promoted`, `TestSlow_Off`, `TestSlow_HealthNever`.
