# M6b plan 1: generator `Spec`s, `alder lsp`, alder.nvim attach and `<leader>aa ac ae ar`

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A language server, `alder lsp`, gives Neovim live diagnostics, hover, go-to-definition, references, completion, the compiler's fixes and the generators as code actions. alder.nvim attaches to it and adds `<leader>aa` (actions, with a `vim.ui.select`/`vim.ui.input` generator flow), `<leader>ac`, `<leader>ae` and `<leader>ar`.

**Architecture:** First the generators are refactored. Each mutating command becomes a declarative `generate.Spec`, with typed fields, a `Here` prefill and an in-process `Run`. The Specs drive argv parsing and `help --json`, and the server calls them as dry runs on a temp copy of the app with the unsaved buffers written over it. The server is a new package, `internal/lsp`. It runs JSON-RPC over stdio on `encoding/json`. Analysis comes from `buildkit.LoadCheckedOverlay` (new). The server keeps the current diagnostics and the last good build, and answers position queries through a new `syntax.NodeAt`. alder.nvim starts the server with `vim.lsp.start`, and plan results are applied as buffer edits by a new `apply.lua`.

**Tech Stack:** Go 1.27 (stdlib only plus `alder/*`), LSP 3.17 with `positionEncoding: "utf-8"`, Lua on Neovim ≥ 0.11 (dev machine 0.12.5), headless Neovim tests.

**Spec:** `docs/superpowers/specs/2026-10-18-m6b-lsp-generator-ui-design.md`. Read it with this plan. Plan 1 covers its sections 1–4 and the parts of section 5 named in "Plan 1" there. The nui picker, form, live preview, review and `<leader>ag` are plan 2.

## Global Constraints

- Go stays dependency-free: stdlib + `alder/*` + the modernc modules already in `go.mod`. `go.mod` gains nothing.
- The server offers only `positionEncoding: "utf-8"`. A compiler position (1-based line, 1-based byte column, exclusive end) maps to LSP as `line-1`, `col-1`. There is no UTF-16 conversion anywhere.
- One server per project root; full document sync; diagnostics pushed with `textDocument/publishDiagnostics`.
- **The plugin never rewords the compiler.** Every diagnostic, refusal and generator message shown in Neovim is the server's or CLI's own text. The plugin's own sentences are exactly these: `alder lsp stopped — :checkhealth alder`, `alder: the language server is not attached (:checkhealth alder)`, `alder: <path> changed since planning; nothing applied`, `alder: nothing applies here; the first line that has something is <n>`, `alder: no diagnostic under the cursor`, `alder: applied <generator>: <files>`, and the remove-confirm prompt in Task 21.
- A plan is applied to **buffers**, never written to disk by the plugin. The one exception is a file the plan removes (Ruling R9). `:Alder <words>` keeps writing to disk through the CLI, as today.
- The existing CLI behaviour stays byte-identical. That covers stdout and stderr goldens under `testdata/generate/want`, refusal texts (`TestGenerate_Refusals`), usage strings (`TestHelp`) and `alder help --json` (a new golden, Task 4). The only exception is Ruling R5.
- Keys under `<leader>a`: `aa` actions, `ac` diagnostics to quickfix, `ae` explain, `ar` run. Each can be set to `false` in `opts.keys`. The which-key group is "alder". `ag` belongs to plan 2.

- `.github/shard-weights` is untouched. New `cmd/alder` tests go in existing test files.
- Code in this plan is written against the surveyed APIs. Where a field or function name differs from the source, follow the source and keep the plan's behaviour. Note each such difference in the commit message.
- Working hours (user rule): no agent or background work 9am–5pm America/New_York on weekdays. Weekends are free. Stop before 9 and record the resume point.

## Rulings over the spec

Found while planning (2026-10-18). They override the spec where they differ.

- **R1 Overlay hook.** `names.Load`'s `extra` modules are *added* under the duplicate rule (E0009), so they cannot overlay a file on disk. A new `names.LoadOverlay(dir, std, overlay, extra...)` reads overlay texts (keyed `app/…/X.alder`, relative to the root) in place of the disk files and adds overlay files missing from disk. `buildkit.LoadCheckedOverlay(dir, overlay)` wraps it. This is the third compiler-side addition of M6b, after `Spec` and `NodeAt`.
- **R2 Plan = `generate.Result`.** There is no separate Plan type. `FileChange` gains `Before, After *string` (`json:"-"`), filled by `Apply` (nil `Before` for a created file, nil `After` for a removed one). `Spec.Run` returns `(*Result, error)`. `Result` also gains `Skipped []string` and `UpToDate bool`, which `regen admin` fills. These were the CLI closure's `skipped`/`nothing`.
- **R3 Migrations are injected.** The migration writer lives in `cmd/alder` (`migrateCopy*`). `generate.App{Dir, Migrate func(dir, slug string) ([]string, error)}` carries it, and slug `""` means `migrateCopy`. `cmd/alder` and the server (through `lsp.Options.Migrate`) pass the same function.
- **R4 Usage text stays hand-written.** The pinned usage strings have grouping (`[--list T | --show T [--by …] | --from T …]`) that no generic renderer reproduces byte for byte. So the usage consts stay in `cmd/alder`, and `help --json`'s generator nodes (args, flags, summaries) are rendered from the Specs. A golden of today's `alder help --json` (Task 4) proves the output is unchanged. The existing flag-set pin keeps the Spec and the usage text in step.
- **R5 Per-Spec flags.** Today `alder edit` parses one flag set (`--to`, `--choose`, `--strict`) for all its subcommands. So `alder edit page … --to X` is accepted and ignored. With Specs, each subcommand accepts only its own flags, and that line becomes a usage error (exit 2, `unknown flag --to` then the usage). This is the only intended CLI change.
- **R6 The subcommand selector** of `edit`, `remove` and `regen` is the first argument that names a Spec of the group (`table`, `page`, …). It is no longer `pos[0]` after flag parsing. The two agree on every command line in the tests.
- **R7 Two workers, no analysis mutex.** Analyses are immutable snapshots behind an `atomic.Pointer`. Fast requests (hover, definition, references, completion, codeAction, `alder/generators`) run in order on one worker. Slow ones (`alder/preview`, `alder/plan`, `workspace/executeCommand`) run on a second worker, so a dry run never blocks hover. Document notifications are applied on the reader goroutine, in order.
- **R8 Generator code actions carry a client command.** A "here" generator's code action has `command: {command: "alder.generate", arguments: [{id, sets, why}]}` as well as `data`. alder.nvim registers `vim.lsp.commands["alder.generate"]`, so Neovim's own `gra` opens the same flow as `<leader>aa`. `executeCommandProvider` lists only `alder.explain`, so the server never receives `alder.generate`.
- **R9 Removed files.** `remove page` and `remove table` can delete a file, and a buffer edit cannot express that. `apply.lua` asks once with `vim.ui.select` (`Delete <path> from disk? undo cannot restore it` / `Yes` / `No`). On Yes it deletes the file with `vim.fs.rm` and wipes its buffer, and on No nothing is applied. This is the plugin's only disk write.
- **R10 New files' directories.** A plan can create `app/Posts/` that does not exist. `apply.lua` marks the new buffers (`b:alder_new = true`), and a `BufWritePre` autocmd creates the parent directory on the first `:w`. Nothing is written before the user saves.
- **R11 Completion reads the text, then the last good build.** The receiver of `x.` and the context (`import `, `<`, `</`, `?`) come from the current overlay text before the cursor. Types come from the last good build, with names resolved through the scope at the same position. The cursor's own line is usually unparseable while typing, so a position is *fresh* for completion when lines `1..line-1` are unchanged since that build. For hover, definition and references, lines `1..line` must be unchanged.
- **R12 Stdlib targets.** `gd` on a stdlib name answers nothing in plan 1, because stdlib files are embedded and have no path. Hover still shows the signature and the doc comment.
- **R13 Schema drift.** Server diagnostics are `alder check`'s: `LoadCheckedOverlay` plus `buildkit.AddSchemaDrift`, as `checkedApp` does. A plan that adds a migration leaves `migrations/*` as unsaved buffers, and E0019 shows until they are saved (`:wall`). This is expected and goes in the README.
- **R14 `:AlderGenerate [id]`** exists in plan 1 and runs the same `vim.ui.select`/`vim.ui.input` flow over every generator. Plan 2 replaces the flow with the nui picker. `:AlderNew`, `:AlderFill` and `fill.lua` are removed.
- **R15 Watcher.** `cmd/alder/run.go`'s `watch`/`snapshot` move to a new package `internal/watch`, so `alder run` and the server share one poller.

## Review Focus

These inputs are the most likely to bite a person using this, and no spec section tests them directly. Each one has a test in the task that owns the code.

1. **Typing breaks the parse.** While a line is half-typed, hover and `gd` above it still answer from the last good build. Below it they return empty, never wrong positions, and the server never panics on a position past the end of the file. Test: Task 11 `TestLastGood`, Task 12 `TestHover_StaleBelowEdit`.
2. **Symlinked roots.** On macOS `/tmp` is `/private/tmp`. A buffer opened through one spelling must get the diagnostics the server computes under the other, and a non-open file must be published under the client's root spelling. Test: Task 11 `TestDiagnostics_SymlinkRoot`.
3. **Multi-byte text before the cursor.** Columns are bytes. Hover, a fix and a completion `textEdit` must land on the right bytes after `é` earlier on the line. Test: Task 12 `TestHover_MultiByte`, Task 15 `TestComplete_MultiByte`.
4. **The buffer changes between preview and apply.** A plan computed, then the buffer edited, then `<CR>` must abort naming the file, not clobber the edit. Test: Task 21 `apply: changed since planning`.
5. **Requests racing edits.** A burst of `didChange` followed by completion must answer from a consistent snapshot. A superseded `alder/preview` is answered `RequestCancelled`, never with an older diff after a newer one. Test: Task 10 `TestCancel_StalePreview`, Task 17 `TestPreview_LatestWins`.

```go
func Load(dir string, std map[string]*syntax.Module, extra ...*syntax.Module) (*Program, *diag.Bag, []error) {
	return LoadOverlay(dir, std, nil, extra...)
}

// LoadOverlay is Load with the files of overlay read from memory instead of disk: an editor's
// unsaved buffers. Keys are paths relative to dir, slash-separated ("app/Posts/Index.alder"); a
// key that is not an .alder file under app/ is ignored. An overlay file the directory does not
// have (a new, unsaved buffer) is added after the directory's files, in path order.
func LoadOverlay(dir string, std map[string]*syntax.Module, overlay map[string][]byte, extra ...*syntax.Module) (*Program, *diag.Bag, []error) {
	var ioErrs []error
	bag := &diag.Bag{}
	var mods []*syntax.Module
	seen := map[string]bool{}
	parse := func(rel string, src []byte) {
		m, ds := syntax.ParseFile(rel, src)
		bag.Items = append(bag.Items, ds...)
		mods = append(mods, m)
		seen[rel] = true
	}
	root := filepath.Join(dir, "app")
	filepath.WalkDir(root, func(path string, d os.DirEntry, err error) error {
		if err != nil {
			ioErrs = append(ioErrs, err)
			return nil
		}
		if d.IsDir() || !strings.HasSuffix(path, ".alder") {
			return nil
		}
		r, _ := filepath.Rel(dir, path)
		rel := filepath.ToSlash(r)
		if src, ok := overlay[rel]; ok {
			parse(rel, src)
			return nil
		}
		src, err := os.ReadFile(path)
		if err != nil {
			ioErrs = append(ioErrs, err)
			return nil
		}
		parse(rel, src)
		return nil
	})
	var added []string
	for rel := range overlay {
		if !seen[rel] && strings.HasPrefix(rel, "app/") && strings.HasSuffix(rel, ".alder") {
			added = append(added, rel)
		}
	}
	sort.Strings(added)
	for _, rel := range added {
		parse(rel, overlay[rel])
	}
	parseFailed := bag.HasErrors()
	// … the rest of the old Load body, unchanged, from `mods = append(mods, extra...)` on …
}
```

## Task 2: Position walker (`syntax.Children`, `NodeAt`, `DocOf`)

**Files:**
- Create: `internal/syntax/walk.go`
- Test: `internal/syntax/walk_test.go`

**Interfaces:**
- Produces:
  - `type Spanned interface{ GetSpan() diag.Span }`
  - `func Children(n Spanned) []Spanned`: direct child nodes in source order.
  - `func NodeAt(m *Module, pos diag.Pos) []Spanned`: the path from `m` (index 0) down to the innermost node whose span contains `pos`. A span contains `pos` when `Start <= pos < End`, in (line, col) order. Nodes with an empty span are skipped. The result is `[m]` when nothing contains the position.
  - `func Contains(sp diag.Span, pos diag.Pos) bool`
  - `func DocOf(lines []string, line int) string`: the contiguous `--` comment lines directly above 1-based `line`, with `--` and one following space stripped, joined by `\n`. It returns `""` when there are none.

```go
// pos finds needle on its line (1-based line, 1-based byte column of the needle plus off).
func pos(t *testing.T, src, needle string, off int) diag.Pos {
	t.Helper()
	for i, l := range strings.Split(src, "\n") {
		if c := strings.Index(l, needle); c >= 0 {
			return diag.Pos{Line: i + 1, Col: c + 1 + off}
		}
	}

	return diag.Pos{}
}
```

```go
package syntax

import (
	"reflect"
	"sort"
	"strings"

	"alder/internal/diag"
)

// Spanned is any AST node: everything that embeds Node.
type Spanned interface{ GetSpan() diag.Span }

var spannedType = reflect.TypeOf((*Spanned)(nil)).Elem()

// Children returns n's direct child nodes in source order, found by reflection over n's fields:
// a field holding a node, a slice of nodes, or a plain struct (StrPart) holding nodes. Nil
// interfaces and pointers are skipped, and so is the embedded Node itself.
func Children(n Spanned) []Spanned {
	var out []Spanned
	var fields func(v reflect.Value)
	var value func(v reflect.Value)
	value = func(v reflect.Value) {
		switch v.Kind() {
		case reflect.Interface, reflect.Pointer:
			if v.IsNil() {
				return
			}
		}
		if v.Type().Implements(spannedType) && v.Kind() != reflect.Struct {
			out = append(out, v.Interface().(Spanned))
			return
		}
		switch v.Kind() {
		case reflect.Slice:
			for i := 0; i < v.Len(); i++ {
				value(v.Index(i))
			}
		case reflect.Struct:
			fields(v)
		}
	}
	fields = func(v reflect.Value) {
		t := v.Type()
		for i := 0; i < v.NumField(); i++ {
			f := t.Field(i)
			if f.Anonymous && f.Type == reflect.TypeOf(Node{}) || !f.IsExported() {
				continue
			}
			value(v.Field(i))
		}
	}
	rv := reflect.ValueOf(n)
	if rv.Kind() == reflect.Pointer {
		rv = rv.Elem()
	}
	if rv.Kind() == reflect.Struct {
		fields(rv)
	}
	sort.SliceStable(out, func(i, j int) bool { return less(out[i].GetSpan().Start, out[j].GetSpan().Start) })
	return out
}

func less(a, b diag.Pos) bool { return a.Line < b.Line || a.Line == b.Line && a.Col < b.Col }

// Contains reports whether pos is in the half-open span [Start, End).
func Contains(sp diag.Span, pos diag.Pos) bool {
	return !less(pos, sp.Start) && less(pos, sp.End)
}

// NodeAt is the path from m down to the innermost node whose span contains pos (index 0 is m).
func NodeAt(m *Module, pos diag.Pos) []Spanned {
	path := []Spanned{m}
	for {
		var next Spanned
		for _, c := range Children(path[len(path)-1]) {
			sp := c.GetSpan()
			if sp.Start == sp.End {
				continue
			}
			if Contains(sp, pos) {
				next = c
			}
		}
		if next == nil {
			return path
		}
		path = append(path, next)
	}
}

// DocOf is the comment block directly above the 1-based line: the run of lines starting with
// `--` ending at line-1, with `--` and one space stripped, joined by newlines.
func DocOf(lines []string, line int) string {
	var doc []string
	for i := line - 2; i >= 0 && i < len(lines); i-- {
		l := strings.TrimSpace(lines[i])
		if !strings.HasPrefix(l, "--") {
			break
		}
		doc = append([]string{strings.TrimPrefix(strings.TrimPrefix(l, "--"), " ")}, doc...)
	}
	return strings.Join(doc, "\n")
}
```

```go
// internal/generate/materialise.go
package generate

import (
	"os"
	"path/filepath"
)

// Materialise copies the app in dir to a temporary directory (as Apply's copy: no build/, .git
// or databases) and writes overlay over it: an editor's unsaved buffers, keyed by path relative
// to dir. A dry run on the copy then sees what the editor sees. cleanup removes the copy.
func Materialise(dir string, overlay map[string][]byte) (string, func(), error) {
	tmp, err := os.MkdirTemp("", "alder-overlay-")
	if err != nil {
		return "", nil, err
	}
	cleanup := func() { os.RemoveAll(tmp) }
	if err := copyApp(dir, tmp, nil); err != nil {
		cleanup()
		return "", nil, err
	}
	for rel, b := range overlay {
		p := filepath.Join(tmp, filepath.FromSlash(rel))
		if err := os.MkdirAll(filepath.Dir(p), 0o755); err != nil {
			cleanup()
			return "", nil, err
		}
		if err := os.WriteFile(p, b, 0o644); err != nil {
			cleanup()
			return "", nil, err
		}
	}
	return tmp, cleanup, nil
}
```

```go
func ParseArgs(s *Spec, argv []string) (Sets, CLIFlags, error) {
	var valued, multi, bools []string
	for _, f := range s.Flags {
		switch {
		case f.Kind == KindBool:
			bools = append(bools, f.Name)
		case f.Greedy:
			multi = append(multi, f.Name)
		default:
			valued = append(valued, f.Name)
		}
	}
	pos, flags, cli, err := ScanArgs(argv, valued, multi, bools)
	if err != nil {
		return nil, cli, err
	}
	sets := Sets{}
	for k, v := range flags {
		sets[k] = v
	}
	for i, a := range s.Args {
		if a.Variadic {
			if len(pos) > i {
				sets[a.Name] = pos[i:]
			} else if a.Required {
				return nil, cli, ErrArity
			}
			pos = nil
			break
		}
		if i >= len(pos) {
			if a.Required {
				return nil, cli, ErrArity
			}
			continue
		}
		sets[a.Name] = []string{pos[i]}
	}
	if len(s.Args) == 0 || !s.Args[len(s.Args)-1].Variadic {
		if len(pos) > len(s.Args) {
			return nil, cli, ErrArity
		}
	}
	return sets, cli, nil
}

// that, after group, is a Spec's ID. It returns the Spec and argv without that word.
func Select(group string, argv []string, specs []*Spec) (*Spec, []string) {

			continue
		}
		for _, s := range specs {
			if s.ID == group+" "+a {
				rest := append(append([]string{}, argv[:i]...), argv[i+1:]...)
				return s, rest
			}
		}
	}
	return nil, argv
}
```

```go
// runEdits is the CLI's generator pipeline (cmd/alder runGeneratorWith without the report):
// load the app, run the generator, apply its edits to a checked copy.
func runEdits(app App, dryRun bool, o Options, load func(string) (*Program, error), gen func(*Program) ([]Edit, error)) (*Result, error) {
	if load == nil {
		load = Load
		if o.WriteDespiteErrors {
			load = LoadWithErrors
		}
	}
	p, err := load(app.Dir)
	if err != nil {
		return nil, err
	}
	edits, err := gen(p)
	if err != nil {
		return nil, err
	}
	o.DryRun = dryRun
	return Apply(app.Dir, edits, o)
}

// migrate is app's migration writer for slug, or a refusal when the caller gave none.

			return nil, Refusef("this generator writes a migration, and no migration writer was given")
```

```go
package lsp

import (
	"bufio"
	"encoding/json"
	"fmt"
	"io"
	"net/textproto"
	"strconv"
	"sync"
)

type rpcError struct {
	Code    int    `json:"code"`
	Message string `json:"message"`
}

func (e *rpcError) Error() string { return e.Message }

type message struct {
	JSONRPC string           `json:"jsonrpc"`
	ID      *json.RawMessage `json:"id,omitempty"`
	Method  string           `json:"method,omitempty"`
	Params  json.RawMessage  `json:"params,omitempty"`
	Result  json.RawMessage  `json:"result,omitempty"`
	Error   *rpcError        `json:"error,omitempty"`
}

func readMessage(r *bufio.Reader) (*message, error) {
	h, err := textproto.NewReader(r).ReadMIMEHeader()
	if err != nil {
		return nil, err
	}
	n, err := strconv.Atoi(h.Get("Content-Length"))
	if err != nil || n < 0 {
		return nil, fmt.Errorf("bad Content-Length %q", h.Get("Content-Length"))
	}
	body := make([]byte, n)
	if _, err := io.ReadFull(r, body); err != nil {
		return nil, err
	}
	var m message
	if err := json.Unmarshal(body, &m); err != nil {
		return &message{Error: &rpcError{codeParse, err.Error()}}, nil
	}
	return &m, nil
}

type conn struct {
	mu   sync.Mutex
	w    io.Writer
	wire io.Writer
}

func (c *conn) send(v any) error {
	b, err := json.Marshal(v)
	if err != nil {
		return err
	}
	c.mu.Lock()
	defer c.mu.Unlock()
	if c.wire != nil {
		fmt.Fprintf(c.wire, "<- %s\n", b)
	}
	_, err = fmt.Fprintf(c.w, "Content-Length: %d\r\n\r\n%s", len(b), b)
	return err
}
```

`server.go` has these parts:

- **Read loop.** For each message: a notification without an id goes to `notifications[method]` on the reader goroutine, and an unknown one is ignored. A request goes to the `fast` or `slow` channel by registry, and an unknown method gets `codeMethodNotFound`. A request before `initialize` gets `codeNotInitialized`, and so does any request after `shutdown`. `$/cancelRequest` stores the id in `cancelled`. On `alder/preview`, the reader stores the request's id in `latestPreview` before queueing it.
- **Workers.** Two goroutines run `for m := range ch { s.handle(m) }`. `handle` answers `codeCancelled` when the id is in `cancelled`, and also when the method is `alder/preview` and the id is not `latestPreview`. Otherwise it runs the handler inside `defer func(){ if r := recover(); r != nil { log stack; reply codeInternal "internal error: <r>" } }()`.
- **Replies.** A handler's `(result, err)` becomes `{id, result}` (`null` for a nil result), or `{id, error}`. A `*rpcError` is sent as is, and any other error as `codeInternal`.
- **Lifecycle.** `initialize` reads `rootUri` (or `rootPath`) into `s.root`, and `filepath.EvalSymlinks(s.root)` into `s.rootReal`. It returns the capabilities below and `serverInfo{name:"alder", version: version.String()}`. `initialized` starts the analysis loop and the poller (Task 11). `shutdown` sets the flag and answers null. `exit` makes `Serve` return nil. EOF on the reader also returns nil.

```go
func (s *server) fresh(a *analysis, rel string, line int, inclusive bool) bool {
	if a == nil {
		return false
	}
	built, ok := a.lines[rel]
	if !ok {
		return false
	}
	now := strings.Split(s.text(rel), "\n") // the open doc's text, else disk
	last := line - 1
	if inclusive {
		last = line
	}
	if last > len(built) || last > len(now) {
		return false
	}
	for i := 0; i < last; i++ {
		if built[i] != now[i] {
			return false
		}
	}
	return true
}
```

```go
func hoverText(a *analysis, m *syntax.Module, path []syntax.Spanned, pos diag.Pos) string {
	n := path[len(path)-1]
	sig := func(name string, t types.Type) string { return "```alder\n" + name + " : " + types.StringIn(t, m.Name) + "\n```" }
	switch n := n.(type) {
	case *syntax.Import:
		return moduleHover(a, n.Module)
	case *syntax.HoleExpr:
		if t, ok := a.res.Types[n]; ok {
			return sig("?"+n.Name, t)
		}
	case *syntax.Var:
		switch n.Ref.Kind {
		case syntax.RefLocal:
			if b := innermost(scopeAt(path, pos), n.Name); b != nil {
				if t, ok := a.res.Binds[b.Key]; ok {
					return sig(n.Name, t)
				}
			}
		case syntax.RefValue, syntax.RefStd:
			key := n.Ref.Module + "." + n.Ref.Name
			t, ok := a.res.Values[key]
			if !ok {
				t, ok = a.res.Types[n], true
			}
			if ok && t != nil {
				return withDoc(sig(n.Name, t), declDoc(a, n.Ref))
			}
		}
	case *syntax.HtmlAttr, *syntax.Element:
		return markupHover(n) // Task 14; until then ""
	}
	if e, ok := n.(syntax.Expr); ok {
		if t, ok := a.res.Types[e]; ok && t != nil {
			return "```alder\n" + types.StringIn(t, m.Name) + "\n```"
		}
	}
	// the cursor on a declaration's name
	if d := declAt(m, pos); d != nil && syntax.Contains(nameSpan(d, m), pos) {
		if vd, ok := d.(*syntax.ValueDecl); ok {
			return withDoc(sig(vd.Name, a.res.Values[m.Name+"."+vd.Name]), syntax.DocOf(m.Lines, vd.Span.Start.Line))
		}
	}
	return ""
}
```

- `declDoc(a, ref)` finds the declaration in `a.prog.Modules[ref.Module]`, or in `a.prog.Std[ref.Module]` for a stdlib name, and returns `syntax.DocOf(mod.Lines, decl.Span.Start.Line)`. If the stdlib modules have no `Lines`, set them in `types.LoadStd` (`m.Lines = strings.Split(src, "\n")`) and say so in the commit.
- `withDoc(a, b)` returns `a` when `b` is empty, else `a + "\n\n" + b`.
- `moduleHover(a, name)` returns `` "`" + name + "` · " + file + " · " + n + " exported declarations" ``. The count is the module's decls. If Alder has no export control, count all decls and drop the word "exported".
- The reply is `{contents: {kind: "markdown", value}}`, or `null` when the text is empty.
- When the innermost node is the `Module` of a qualified `Posts.Index.x` and the cursor is on the qualifier, hover shows the module. `NodeAt` gives the `*Var` with `Module` set; when the cursor column is within the `Module` prefix of the `Var`'s span, answer `moduleHover`.

**`nameSpan(d, m)`** is the span from the declaration's start to `start + len(name)` on its first line. For a `ValueDecl` with a signature, the declaration starts at the signature line `name : …`; check `vd.Span.Start` against the source.

**Definition:**

- A `RefValue`/`RefType`/`RefCtor`/`RefPage`/`RefTable`/`RefComponent`/`RefCapability` goes to the declaration in `prog.Modules[ref.Module]`, at its name span. A ctor goes to its `*Ctor` in its union.
- An `*Access` whose base type is a named `*types.Record` with a `Def` goes to the field in that record's declaration.
- A local goes to the binder's span. A module goes to `{uri, range: 0:0-0:0}`. A stdlib name gives `[]` (R12).
- The reply is `[]Location` of `{uri: s.uriOf(m.File), range}`.

The context comes from the open text's current line up to the cursor (`prefix`):

| prefix matches | items |
|---|---|
| `^\s*import\s+([A-Za-z.]*)$` | module names of the program and stdlib (kind 9 Module) |
| `([A-Z][A-Za-z0-9]*(?:\.[A-Z][A-Za-z0-9]*)*)\.([a-zA-Z0-9_]*)$`, where group 1 is a module | that module's declarations: values (kind 3 Function, or 6 Variable for non-functions) with detail `name : Type`, types (7 Class), ctors (4 Constructor) |
| `([a-z][A-Za-z0-9_]*)\.([a-zA-Z0-9_]*)$`, where group 1 is in scope with a record type | its fields (kind 5 Field), detail `name : Type` |
| `</([a-z0-9-]*)$` | the innermost unclosed tag before the cursor (kind 10 Property) |
| `<([a-z][a-z0-9-]*)\s[^<>]*?\b([a-z-]*)$` | `AttrsOf(group 1)`, label `name`, newText `name=""` for non-boolean and `name` for boolean (kind 10) |
| `(?:^|[\s>({\[,])<([a-z0-9-]*)$` | tag names (kind 10), detail = description |
| `\?([a-z][A-Za-z0-9_]*)?$`, or the cursor inside a `HoleExpr` in the last good build | names in scope whose type fits the hole (sortText `0…`), then all others (`1…`) |
| the cursor inside a pattern of a `Match`/`HtmlMatch` arm in the last good build | the ctors of the subject's union (kind 4) |
| otherwise | locals in scope, the module's declarations, imported module qualifiers, stdlib modules, keywords (kind 14) |

`textEdit.range` covers the identifier under the cursor: the bytes from its start (after the last `.`, `<`, `</`, `?` or space) to the cursor, as a utf-8 character offset. No snippets.

**Scope at a cursor on a half-typed line (R11).** Take `declAt` of the last good module at the cursor's position. If the line is past the declaration's end, use the declaration containing the line above. Then compute `scopeAt(syntax.NodeAt(m, pos'), pos')`, where `pos'` is the end of the line above. This gives the names bound before the line being typed.

**A type fits the hole** when `types.Unify` succeeds on a fresh unifier: `u := &types.Unifier{Subst: map[int]types.Type{}}` (or the package's constructor), then `u.Check(u.Instantiate(valueType), holeType) == nil`. Never use `a.res.U`, because that would mutate the analysis.

```go
func (s *server) dryRun(id string, you map[string]string, rel string, pos diag.Pos) (spec *generate.Spec, fields []generate.FieldState, res *generate.Result, ready bool, err error) {
	spec = generate.SpecByID(id)
	if spec == nil {
		return nil, nil, nil, false, &rpcError{codeInvalidParams, "no generator " + id}
	}
	var here *generate.Match
	if a := s.lastGood(); a != nil && spec.Here != nil && s.fresh(a, rel, pos.Line, true) {
		here = spec.Here(hereCtx(a, rel, pos))
	}
	tmp, cleanup, err := generate.Materialise(s.rootReal, s.docs.overlay())
	if err != nil {
		return spec, nil, nil, false, err
	}
	defer cleanup()
	p, _ := generate.Load(tmp) // nil when the app does not check: fields still validate syntactically
	fields, sets, ready := generate.Form(spec, here, you, p)
	if !ready {
		return spec, fields, nil, false, nil
	}
	res, err = spec.Run(sets, generate.App{Dir: tmp, Migrate: s.o.Migrate}, true)
	return spec, fields, res, ready, err
}
```

`files[].added`/`removed` count the `+`/`-` lines of that file in `res.Diff`, using `generate.UnifiedDiff` per file from `Before`/`After` (empty string for nil).         end
```lua
      end)
    end,
  }, { bufnr = buf, reuse_client = function(c, conf) return c.name == 'alder' and c.root_dir == conf.root_dir end })

function M.client(buf)
  return vim.lsp.get_clients({ bufnr = buf, name = 'alder' })[1]
end

function M.request(buf, method, params, cb)
  local c = M.client(buf)
  if not c then

    return
  end

    if err then
      if err.code ~= -32800 then vim.notify(err.message, vim.log.levels.ERROR) end
      return
    end
    cb(result)
  end, buf)
end
```
