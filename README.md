# Alder

An Elm-inspired, deliberately constrained language for server-rendered web
applications, designed so that AI agents write correct programs in it.

- `book/` — the language reference and design rationale. Start at `book/README.md`.
- `examples/` — complete example applications.
- `experiments/` — prompts, outputs, and scores from running models against the language.

Status: design phase. No compiler yet.
